## Names

The three repositories live under the GitHub account `abdou-rgd` since 2026-10-16 (the organisation `officina-dmpk` is kept reserved and empty; its old links do not redirect). Name check on 2026-10-08: `officina` is free on crates.io, PyPI and npm. This is a name availability check, not a trademark search: the audit of 2026-10-14 found live US trademarks on "Caladrius" in pharma and software, so a trademark search (EUIPO, INPI, WIPO) is due before any wider communication; `caladrius` stays the crate name.

## Roadmaps

Roadmap, reordered on 2026-10-16 after an external audit (the audit itself is summarised in [METHOD.md](METHOD.md#6-the-audit-of-14-october)): merge the audit's documentation fixes (done) → publish OptChat (done) → frozen, pre-registered out-of-sample test set for Apothicaire → number gate v2 (typed rendering from the MCP `structuredContent`: the renderer prints the engine's value, sign, unit and parameter name, and only closed lists of quantities can be cited; implemented and measured in-sample on 2026-10-17: 183/200 turns, 17/874 quantities shown as visible markers, kept behind a flag until the frozen set) → run on upstream `llama.cpp` with the `Q2_0` packing (no vendor fork; done 2026-10-17 for the 27B: 193/200 turns, 0/897 unverified numbers, the runtime of the demonstration), 9B judged on the frozen set → Caladrius validation kit (reference sets, tolerances, regenerable execution report, traceability to ICH M15/M13A, a script that regenerates every README figure and a CI check against drift) → an abstract for PAGE 2027 on the independent comparison of open NCA tools. First public demonstration: 17 November 2026.

Previous roadmap (reordered on 2026-10-09 after two independent reviews, `notes/review-*.md`): Caladrius steps 1-5 done (engine, CLI, MCP, UI) → v0.1.0 release with CI, CITATION.cff and an honest validation section (coverage per model, tolerance note, missing fit oracles) → deterministic number gate and digest tests in Apothicaire, hallucination rate reported with its denominator → DMPK benchmark of ~25 exercises simulated by Caladrius → two-compartment models with oracle → only then UI polish, wasm demo, decision models (routing and plot questions), Pi Durable if the benchmark justifies it. Apothicaire stays in Python until then.
